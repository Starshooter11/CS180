Among the first things that pop up most often in image editing options is sharpening and blurring. Remember how the Gaussian filter blurs things? Well, as it turns out, if you remove the blurred parts(cough low pass filter cough) from the image, you get the high pass version! Then, we readd this high pass version(multiplied by an alpha to control how much we're adding) back to the image and we obtain the sharpened version! Here's the Taj Mahal:

Alright, as the title already gave away, time to make hybrid images! Basically, these are images that look predominantely like one object when viewed up close, but look like another when viewed far away. This is because high frequency tends to dominante at close distances while low frequency dominates at a distance. FOr the purposes of this project, all images are taken in grayscale. Part2.3: Gaussian and Laplacian Stacks

Here, I implemented a Gaussian and a Laplacian stack. Here, unlike the pyramid introduced in a previous project, the images are never downsampled so the results are all the same dimension. The Gaussian Stack is created by applying the Gaussian filter at each level. The Laplacian is then the differences between subsequent gaussian filtered images. Using the same orange and apple pictures from Szelski's 'Oraple', we can create the same stack. I also did the same vertical split.
